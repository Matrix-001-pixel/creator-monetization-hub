# CreatorHub MVP

A lightweight MVP for a creator monetization platform.

## Highlights

- Creator onboarding for users with 1,000+ followers
- Multiple monetization streams: sponsorships, affiliate offers, tips, memberships, digital products
- Transparent 10% transaction commission
- Payout calculator UI
- Landing page + dashboard-style experience

## Run locally

Open `index.html` directly in a browser.

## Suggested next steps

- Add real authentication and user profiles
- Connect a backend database and Stripe API
- Build a creator dashboard with real data
- Add admin tools for payouts and campaign approvals

## Deploy

This static MVP can be deployed to Vercel, Netlify, or GitHub Pages with no build step.
